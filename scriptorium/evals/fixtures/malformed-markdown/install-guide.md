# Install guide

Follow these steps to install the CLI locally.

#Prerequisites

You need a POSIX shell and curl on your PATH.

####### Requirements

The requirements below assume a Linux or macOS host.

This step downloads the binary and places it on PATH.  
Run the installer script from a shell you trust.

```bash
#!/usr/bin/env bash
#include <stdio.h>
	echo "tab-indented line inside the fence"
```

After installation, run `--version` to confirm the binary works.
